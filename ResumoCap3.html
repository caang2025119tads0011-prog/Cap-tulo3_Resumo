Capítulo 3 - CSS


1.0 CSS

Linguagem de estilo usada para controlar a aparência dos elementos HTML. Permite alterar fontes, cores, listas, formulários, tabelas e layouts.

2.0 Princípio do CSS

Uma regra CSS possui: 

seletor {
    propriedade: valor;
}

Exemplo:

body {
    font-family: Arial;
}

2.1 Incluindo CSS em HTML

Existem três formas principais:

  • External CSS → arquivo separado .css(no head)
  • Internal CSS → uso da tag <style>(no head)
  • Inline CSS → CSS direto no elemento HTML

Exemplo de External:


<link href="css/styles.css" type="text/css" rel="stylesheet" />

Exemplo de Internal:


<style type="text/css">
   body {
	font-family: Arial;
	background-color: lightblue;
   }
   h1 {
	color: darkblue;
   }
   h2 {
	text-transform: uppercase;
   }
<style>

Exemplo de Inline:


	<body style="font-family: Arial; background-color: lightblue;">
		<h1 style="color: darkblue;">My first web page</h1>
		<p>This is a paragraph.</p>
		<h2 style="text-transform: uppercase;">
		This is a subheading
		</h2>
		<p>
		Here is another paragraph with <i>italics</i> and
		<b>bold text</b>.
		</p>
		<h2 style="text-transform: uppercase;">
		This is another subheading
		</h2>
	</body>

2.2 Seletores

Os seletores definem quais elementos receberão estilo.

  • Tipo: h1, p, body -> todos o elementos da tipo selecionado
  • Classe: .classe -> baseado em uma classe de Css
  • ID: #id -> seleciona os que tem ID correspondente
  • Universal:* -> seleciona todos
  • Atributo: [type="text"] -> seleciona baseado no valor dos atributos
Tipo:

h1 {
    color: green;
}

ID:

#titulo {
    color: blue;
}

Classes:

.texto {
    font-size: 20px;
}

Atributo:

[type= "text"]{
	color: green;
}

2.3 Cascata e Especificidade

O CSS funciona em cascata. Regras mais específicas possuem prioridade. 

h1 {
    color: blue;
}

h1 {
    color: green;
}

Nesse caso, a cor verde será aplicada porque foi declarada depois.

O seletor mais específico ganha a preferência em Css. 

h1 {
	color: green;
}
h1.chapter {
	color: orange;
}
*{
	color: blue;
	background-color: yellow;
}

Nesse caso o h1 ganha preferência de *, pois ele é mais específico.

2.4 Herança

Algumas propriedades são herdadas pelos elementos filhos, como:

  • color
  • font-family

3.0 Cores e Formatação de Texto

3.1 Definindo cores

h1 {
    color: darkblue;
}

p {
    color: rgb(169,169,169);
}

Formatos aceitos:

  • Nome da cor
  • RGB -> escolhe números de 0 a 255 que definem a composição de vermelho, verde e azul
  • Hexadecimal ->define o valor com número hexadecimais(EX:# FFFF00)
  • RGBA -> quarto número que define quâo transparente é (de 0.0 a 1.0)
  • HSL -> pode definir saturação, opacidade iluminação com números de 0 a 360
h1 {
	color: darkblue;
}
h2 {
	color: #ffa500;
}
p{
	color: rgb(169, 169, 169);
}
body {
	background-color: grey;
}
11 {
	background-color: #ffa500;
}
p{
	background-color: rgb(169, 169, 169);
}

3.2 Fontes

body {
    font-family: Arial, sans-serif;
}

Tipos comuns:

  • serif -> fonte com pequenos ganchos nos traços principais
  • sans-serif -> fonte sem sem ganchos, pega a principal do sistema(Ex: Arial)
  • monospace -> fonte onde todos possuem a mesma largura
  • cursive ->Fonte cursiva ou itálica, ou seja, uma fonte que se assemelha à escrita à mão.
  • fantasy -> família de fontes genérica usada para estilos decorativos, artísticos ou temáticos. 

body {
	font-family: 'Times New Roman', Times, serif;
}
h1, h2 {
	font-family: Arial, sans-serif;
}
ul li {
	font-family: 'Courier New', Courier, monospace;
}
.author {
	font-family: Verdana;
}
.date {
	font-family: 'Courier New', Courier, monospace;
}

3.3 Tamanho e estilo da fonte

font size de 14 pixels:

body {
    font-size: 14px;
}

150% do tamanho normal da fonte:
h1 {
    font-size: 150%;
}
1,5 vezes a largura da letra m:

h2 {
font-size: 1.5em;
}

define fonte como itálico e negrito
.introducao {
    font-style: italic;
    font-weight: bold;
}

3.4 Outras formatações

  • text-transform ->Você pode usar a propriedade text-transform para alternar entre diferentes notações.
  • text-decoration ->a Abreviatura usada para adicionar linhas visuais, como sublinhados, sobrelinhados e tachados, ao texto.
  • text-align ->usada para controlar o alinhamento horizontal do conteúdo inline (como texto ou imagens) dentro de um elemento de bloco.
  • line-height ->define a altura
  • letter-spacing -> define o espaço entre as letras
h2 {
    text-transform: uppercase;
    text-decoration: underline;
}

3.5 Links

a:hover {
    color: black;
    background-color: orange;
}

Pseudo-classes importantes:

  • :link -> Estiliza links que ainda não foram clicados ou visitados pelo usuário.
  • :visited -> Modifica a aparência de links que o usuário já acessou anteriormente.
  • :hover ->Ativa os estilos quando o usuário passa o cursor do mouse sobre o elemento.
  • :active ->Aplica a estilização no exato momento em que o elemento é clicado.
  • :focus ->Destaca o elemento quando ele recebe seleção via teclado ou clique.

4.0 Listas e Tabelas

4.1 Listas

ul li {
    list-style-type: square;
}

Valores comuns:

  • disc -> Define o marcador da lista como um círculo preenchido (padrão do navegador).
  • circle -> Transforma o marcador da lista em um círculo vazado com contorno fino.
  • square ->Altera o marcador da lista para o formato de um quadrado preenchido.
  • none -> Remove completamente qualquer marcador visual da lista, ocultando os pontos.

4.2 Listas ordenadas

ol li {
    list-style-type: lower-roman;
}

Também é possível usar:

  • decimal -> Exibe a lista numerada com algarismos arábicos tradicionais começando do 1 (padrão).
  • upper-alpha -> Ordena a lista utilizando letras maiúsculas da A até a Z.
  • lower-alpha -> Organiza a lista utilizando letras minúsculas da a até a z.

4.3 Imagens em listas

ul li {
    list-style-image: url("estrela.png");
}

4.4 Tabelas

table {
    border-collapse: collapse;
}

th, td {
    padding: 10px;
}

O CSS permite melhorar a aparência das tabelas usando bordas, cores, alinhamento e espaçamento.

5.0 Sistemas de Layout

5.1 Tipos de posicionamento

  • static -> Posicionamento padrão que segue o fluxo natural de renderização da página HTML.
  • relative -> Move o elemento com base em si mesmo sem alterar o fluxo dos outros.
  • absolute -> Posiciona o elemento em relação ao ancestral mais próximo que não seja estático.
  • fixed -> Fixa o elemento em relação à tela do navegador, ignorando a rolagem da página.
  • sticky -> Alterna entre relativo e fixo dependendo da posição de rolagem do usuário na tela.
div {
    position: relative;
}

5.2 Float Layout

label {
    float: left;
}

input {
    float: left;
}

O float foi muito usado para organizar formulários e layouts antigos.

5.3 Flexbox

.form-row {
    display: flex;
    justify-content: flex-end;
}

O Flexbox facilita alinhamento horizontal e vertical de elementos. Ele é bem mais flexivel que o float layout.

Flex containers:

  • flex-direction -> Especifica a direção em que os itens flexíveis são organizados em um contêiner flexível.
  • flex-wrap -> Especifica a direção em que os itens flexíveis são organizados em um contêiner flexível. Controla se o contêiner flexível é de linha única ou de várias linhas.
  • flex-flow ->Propriedade abreviada para flex-direction e flex-wrap properties.
  • justify-content -> Define como o espaço disponível deve ser distribuído entre os itens flexíveis.
  • align-items -> Define a orientação padrão de todos os elementos para o outro eixo do contêiner flexível.
  • align-content -> Define a disposição de itens flexíveis individuais em contêineres flexíveis de várias linhas.

Flex Items:

  • order -> Determina a ordem dos itens flexíveis individuais. Um valor numérico representando a posição do respectivo item flexível pode ser especificado como o valor.
  • align-self -> Semelhante a align-items, mas se refere a itens flexíveis individuais.
  • flex-basis ->Controla, por meio de um valor numérico, o tamanho máximo que um elemento pode atingir ao longo do eixo principal antes de crescer ou diminuir.
  • flex-grow -> Determina, por meio de um valor numérico, o quanto um elemento pode crescer em relação aos seus elementos irmãos.
  • flex-shrink ->Determina, por meio de um valor numérico, o quanto um elemento diminui em relação aos seus elementos irmãos.
  • flex -> Abreviação de "propriedade" para as três propriedades anteriores.Propriedades.

5.4 Grid Layout

.container {
    display: grid;
}

O Grid Layout organiza elementos em linhas e colunas, sendo ideal para layouts complexos. Ele é "two-dimensional" ,ou seja, evolve a posição dos elementos, em contraste o "one-dimensional" que é p Flexbox

Grid conteiners:

  • grid-template-areas -> Define a estrutura e a posição dos elementos da grade definidos por meio da área da grade.
  • grid-template -> Define a propriedade structurShorthand para grid-auto-columns, grid-auto-flow, grid-auto-rows e gridtemplate.e e a posição dos elementos da grade definidos por meio de grid-area.
  • grid ->Propriedade abreviada para grid-auto-columns, grid-auto-flow, grid-auto-rows e gridtemplate.
  • justify-items ->Define o alinhamento de todos os itens da grade dentro do contêiner da grade.
  • align-items -> Define para um contêiner de grade como os itens individuais da grade são posicionados ao longo do eixo transversal.
  • justify-content -> Define a direção do eixo principal ao longo do qual os itens da grade estão orientados.
  • align-content -> Define como os itens individuais da grade são posicionados ao longo do eixo transversal (o eixo transversal é definido como qualquer eixo que não seja o eixo principal).
  • row-gap -> Define as distâncias entre as linhas individuais de uma grade.
  • column-gap -> Define as distâncias entre as colunas individuais de uma grade.
  • gap -> Propriedade abreviada para espaçamento entre linhas e espaçamento entre colunas.

Grid Itens:

  • grid-row-start ->Define o início vertical de uma área da grade.
  • grid-column-start -> Define o início horizontal de uma área da grade.
  • grid-row-end -> Define o limite vertical de uma área da grade.
  • grid-column-end -> Define o limite horizontal de uma área da grade.
  • grid-row ->Shorthand property for grid-row-start and grid-row-end.
  • grid-column ->Propriedade abreviada para grid-column-start e grid-column-end.
  • grid-area ->Propriedade abreviada para linha de grade e coluna de grade.
  • justify-self -> Define o alinhamento de um item da grade dentro do contêiner da grade.
  • align-self ->Define para um item da grade como um único item da grade é posicionado ao longo do eixo transversal.
