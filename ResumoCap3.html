Capítulo 3 - CSS


1.0 CSS

Linguagem de estilo usada para controlar a aparência dos elementos HTML. Permite alterar fontes, cores, listas, formulários, tabelas e layouts.

2.0 Princípio do CSS

Uma regra CSS possui: 

seletor {
    propriedade: valor;
}

Exemplo:

body {
    font-family: Arial;
}

2.1 Incluindo CSS em HTML

Existem três formas principais:

  • External CSS -> arquivo separado .css(no head)
  • Internal CSS -> uso da tag <style>(no head)
  • Inline CSS -> CSS direto no elemento HTML

Exemplo de External:


<link href="css/styles.css" type="text/css" rel="stylesheet" />

Exemplo de Internal:


<style type="text/css">
   body {
	font-family: Arial;
	background-color: lightblue;
   }
   h1 {
	color: darkblue;
   }
   h2 {
	text-transform: uppercase;
   }
<style>

Exemplo de Inline:


	<body style="font-family: Arial; background-color: lightblue;">
		<h1 style="color: darkblue;">My first web page</h1>
		<p>This is a paragraph.</p>
		<h2 style="text-transform: uppercase;">
		This is a subheading
		</h2>
		<p>
		Here is another paragraph with <i>italics</i> and
		<b>bold text</b>.
		</p>
		<h2 style="text-transform: uppercase;">
		This is another subheading
		</h2>
	</body>

2.2 Seletores

Os seletores definem quais elementos receberão estilo.

  • Tipo: h1, p, body -> todos o elementos da tipo selecionado
  • Classe: .classe -> baseado em uma classe de Css
  • ID: #id -> seleciona os que tem ID correspondente
  • Universal:* -> seleciona todos
  • Atributo: [type="text"] -> seleciona baseado no valor dos atributos
  • Adjacent sibling selectors h1+p -> seleciona o elemento que segue o outro
  • General sibling selectors: h1~p -> Seleciona elementos que seguem outro elemento (mas não necessariamente imediatamente).
  • Child selectors: body > ul -> Seleciona elementos que são elementos filhos diretos do outro elemento definido no seletor.
  • Descendant selectors: body ul -> Seleciona elementos que são descendentes do outro elemento definido no seletor (mas não necessariamente elementos filhos diretos).
Tipo:

h1 {
    color: green;
}

ID:

#titulo {
    color: blue;
}

Classes:

.texto {
    font-size: 20px;
}

Atributo:

[type= "text"]{
	color: green;
}

Tipos de atributos seletores

  • [attribute~=value]: -> O atributo contém, como seu valor, uma lista da qual um elemento da lista corresponde exatamente ao valor.
  • [attribute|=value]: -> O atributo tem exatamente o valor especificado valor, ou o valor foi hifenizado e começa com valor seguido de um hífen.
  • [attribute^=value]: -> O atributo tem um valor que começa com valor.
  • [attribute$=value]: -> O atributo tem um valor que termina com valor.
  • [attribute*=value]: ->O atributo tem um valor que contém o valor pelo menos uma vez.
    • Um elemento da lista corresponde exatamente a valor.

    2.3 Cascata e Especificidade

    O CSS funciona em cascata. Regras mais específicas possuem prioridade. 

    h1 {
    color: blue;
}

h1 {
    color: green;
}

    Nesse caso, a cor verde será aplicada porque foi declarada depois.

    O seletor mais específico ganha a preferência em Css. 

    h1 {
	color: green;
}
h1.chapter {
	color: orange;
}
*{
	color: blue;
	background-color: yellow;
}

    Nesse caso o h1 ganha preferência de *, pois ele é mais específico.

    Calcular a especifidade: é baseada em 3 valores (0,0,0) inicialmente 0, para adicionar 1 no primeiro precisa ser ID, o segundo precisa ser atributo, classe ou pseudo-classe, já a terceira basta ser um seletor ou pseudo seletor, a única exeção a regra é *. 

    * {} /* A=0, B=0, C=0, specificity --> 000 */
h1 {} /* A=0, B=0, C=1, specificity --> 001 */
ol li {} /* A=0, B=0, C=2, specificity --> 002 */
div:first-child {} /* A=0, B=1, C=1, specificity --> 011 */
a.tests[href] {} /* A=0, B=2, C=1, specificity --> 021 */
#anchor {} /* A=1, B=0, C=0, specificity --> 100 */
#chapter p {} /* A=1, B=0, C=1, specificity --> 101 */

    2.4 Herança

    Algumas propriedades são herdadas pelos elementos filhos, como font-family e color, basta que o elemento sejá o portador da regra para que seus semelhantes (filhos) herde, essas regras 

    Ex:
h1{
	font-family:Arial
	color:blue
}

#agora todos os h1 filhos irão herdar a mesma regra

    sendo a exceção a essa regra border que mexe com células de tabelas

    3.2 Fontes

    Usa a propriedade font-family

    body {
    font-family: Arial, sans-serif;
}

    Tipos comuns:

    • serif -> fonte com pequenos ganchos nos traços principais
    • sans-serif -> fonte sem sem ganchos, pega a principal do sistema(Ex: Arial)
    • monospace -> fonte onde todos possuem a mesma largura
    • cursive ->Fonte cursiva ou itálica, ou seja, uma fonte que se assemelha à escrita à mão.
    • fantasy -> família de fontes genérica usada para estilos decorativos, artísticos ou temáticos. 
    
body {
	font-family: 'Times New Roman', Times, serif;
}
h1, h2 {
	font-family: Arial, sans-serif;
}
ul li {
	font-family: 'Courier New', Courier, monospace;
}
.author {
	font-family: Verdana;
}
.date {
	font-family: 'Courier New', Courier, monospace;
}

    3.4 Outras formatações

    • text-transform ->Você pode usar a propriedade text-transform para alternar entre diferentes notações, com valores uppercase(maiúsculo) e lowercase(minúsculo), além de capitaliza que seleciona a primeira letra de todas as frases e deixa maiúscula.
    • text-decoration ->a Abreviatura usada para adicionar linhas visuais (blink), como sublinhados (underline), sobrelinhados (overline) e tachados(line-through), ao texto.
    • text-align ->usada para controlar o alinhamento horizontal do conteúdo inline (como texto ou imagens) dentro de um elemento de bloco. Valores como alinhamento a esquerda(left value), centro(center), rigth(direita) e justify.
    • vertical-aling -> usado para alinhamento vertical, pode alinhar com valores top,button or middle
    • line-height -> propriedade que define a altura da linha
    • letter-spacing -> propriedade que define o espaço entre as letras
    • word-spacing -> propriedade que define o espaço entre as palavras
    • text-shadow -> coloca efeito de sombra nas letras.
    • text-intent -> recua a primeira linha do texto.
    h2 {
    text-transform: uppercase;
    text-decoration: underline;
}

    3.5 Links

    a:hover {
    color: black;
    background-color: orange;
}

    Pseudo-classes importantes:

    • :link -> Estiliza links que ainda não foram clicados ou visitados pelo usuário.
    • :visited -> Modifica a aparência de links que o usuário já acessou anteriormente.
    • :hover ->Ativa os estilos quando o usuário passa o cursor do mouse sobre o elemento.
    • :active ->Aplica a estilização no exato momento em que o elemento é clicado.
    • :focus ->Destaca o elemento quando ele recebe seleção via teclado ou clique.

    4.0 Listas e Tabelas

    Iremos usar a propriedade list-style-type para especificar a aparência das listas tanto ordenadas como desordenadas.

    4.1 Listas Desordenadas

    ul li {
    list-style-type: square;
}

    Na desordenada modificamos o ponto preto que é conhecido como bala

    • none -> nenhuma bala é usada.
    • disc -> a bala é um disco preto.
    • circle -> a bala é um circulo branco com bordas pretas.
    • square -> a bala vira um quadrado preto.

    Pode usar também list-style position para posicionar a bala, com o valor inside deixa ela dentro da caixa de texto e o overside deixa fora.

    ol li {
    list-style-type: lower-roman;
}

    Nas listas ordenadas modificamos a aparência dos números.

    • decimal -> Enumeração normal dos números naturais(1234...)
    • decimal-leading-zero -> Os números com 1 digito tem 0 na esquerda (01,02,03,...,09,10,11).
    • lower-alpha -> enumera por meio das letras minúsculas do alfabeto( a,b,c ...)
    • upper-alpha -> enumera por meio das letras maiúsculas do alfabeto( A,B,C ...)
    • lower-roman -> números romanos só que minúsculos(i,ii,iii...)
    • upper-roman -> números romanos só que maiúsculos(I,II,III...)

    4.3 Imagens em listas

    Podemos colocar uma imagem no lugar da bala, usando list-style-image, com valor url("caminho do arquivo"). 

    ul li {
    list-style-image: url("estrela.png");
}

    4.4 Tabelas

    table {
    border-collapse: collapse;
}

th, td {
    padding: 10px;
}

    Aqui irei mencionar algumas propriedes e pseudo-classes capas de modificar tabelas

    • border -> usado para modificar as bordas em largura(definida por pixels), estilo(solid) e cor(#000000)
    • border-collapse -> usado para controlar a estrutura e exibição de bordas na tela, pode "colapsar" as bordas e fazer a células compartilharem a mesma borda.
    • padding -> usada para definir o espaço existente entre a contente e a células e suas bordas.
    • :first-child -> pega todos os primeiros elementos filhos dos tipos dados(ex: td:first-child pega todos os primeiros td)\
    • :nth-child() -> pseudo-classe pode localizar elemento filho atraves da posição específica colocado no parêmetro. Pode colocar em uma posição odd :nth-child(odd) ou even :nth-child(even)

    tipos de border:

    • border-top-width;
      border-right-width;
      border-bottom-width;
      border-left-width
      para definir largura
    • border-top-style;
      border-right-style;
      border-bottom-style;
      border-left-style;
      para estilo
    • border-top-color;
      border-right-color;
      border-bottom-color;
      border-left-color;
      definir cor

    O CSS permite melhorar a aparência das tabelas usando bordas, cores, alinhamento e espaçamento.

    5.0 Sistemas de Layout

    A diferença de elementos block-level e inline-level é que o block é executado pelo browser em uma nova linha, enquanto o inline é executado na mesma linha que foi colocado no código

    5.1 Tipos de posicionamento

    • static -> Posicionamento padrão que segue o fluxo natural de renderização da página HTML.
    • relative -> Move o elemento com base em si mesmo sem alterar o fluxo dos outros.
    • absolute -> Posiciona o elemento em relação ao ancestral mais próximo que não seja estático.
    • fixed -> Fixa o elemento em relação à tela do navegador, ignorando a rolagem da página.
    • sticky -> Alterna entre relativo e fixo dependendo da posição de rolagem do usuário na tela.
    div {
    position: relative;
}

    5.2 Float Layout

    label {
    float: left;
}

input {
    float: left;
}

    O float foi muito usado para organizar formulários e layouts antigos. Permite você por elementos na direita e esquerda ao redor do HTML, mas hoje não é mais tão utilizado, pois foi ultrapassado pelos seus sucessores, flex layout e grid layout, como mostrado no exemplo acima ele pode ser usado em vários seletores como label, button, input. Overflow garante que o elemento mantenha sua altura e width e max-width servem para definir largura.

    5.3 Flexbox

    .form-row {
    display: flex;
    justify-content: flex-end;
}

    O Flexbox facilita alinhamento horizontal e vertical de elementos. Ele é bem mais flexivel que o float layout. Esse layout pode ter arranjos verticais e arranjos horizontais que evitam o overflow, além de ter grande nível de manipulação vertical e horizontal de espaços entre elementos e poder alinhar espaço entre itens e outas coisas.

    Flex containers:

    • display -> Define um elemento como um contêiner flexível com o valor flex.
    • flex-direction -> Especifica a direção em que os itens flexíveis são organizados em um contêiner flexível.
    • flex-wrap -> Especifica a direção em que os itens flexíveis são organizados em um contêiner flexível. Controla se o contêiner flexível é de linha única ou de várias linhas.
    • flex-flow ->Propriedade abreviada para flex-direction e flex-wrap properties.
    • justify-content -> Define como o espaço disponível deve ser distribuído entre os itens flexíveis.
    • align-items -> Define a orientação padrão de todos os elementos para o outro eixo do contêiner flexível.
    • align-content -> Define a disposição de itens flexíveis individuais em contêineres flexíveis de várias linhas.

    Flex Items:

    • order -> Determina a ordem dos itens flexíveis individuais. Um valor numérico representando a posição do respectivo item flexível pode ser especificado como o valor.
    • align-self -> Semelhante a align-items, mas se refere a itens flexíveis individuais.
    • flex-basis ->Controla, por meio de um valor numérico, o tamanho máximo que um elemento pode atingir ao longo do eixo principal antes de crescer ou diminuir.
    • flex-grow -> Determina, por meio de um valor numérico, o quanto um elemento pode crescer em relação aos seus elementos irmãos.
    • flex-shrink ->Determina, por meio de um valor numérico, o quanto um elemento diminui em relação aos seus elementos irmãos.
    • flex -> Abreviação de "propriedade" para as três propriedades anteriores.Propriedades.

    5.4 Grid Layout

    .container {
    display: grid;
}

    O Grid Layout organiza elementos em linhas e colunas juntas, sendo ideal para layouts complexos. Ele é "two-dimensional" ,ou seja, evolve a posição dos elementos, em contraste o "one-dimensional" que é o Flexbox que só pode merxer linha e coluna por vez.

    Grid conteiners:

    • grid-template-areas -> Define a estrutura e a posição dos elementos da grade definidos por meio da área da grade.
    • grid-template -> Define a propriedade structurShorthand para grid-auto-columns, grid-auto-flow, grid-auto-rows e gridtemplate.e e a posição dos elementos da grade definidos por meio de grid-area.
    • grid ->Propriedade abreviada para grid-auto-columns, grid-auto-flow, grid-auto-rows e gridtemplate.
    • justify-items ->Define o alinhamento de todos os itens da grade dentro do contêiner da grade.
    • align-items -> Define para um contêiner de grade como os itens individuais da grade são posicionados ao longo do eixo transversal.
    • justify-content -> Define a direção do eixo principal ao longo do qual os itens da grade estão orientados.
    • align-content -> Define como os itens individuais da grade são posicionados ao longo do eixo transversal (o eixo transversal é definido como qualquer eixo que não seja o eixo principal).
    • row-gap -> Define as distâncias entre as linhas individuais de uma grade.
    • column-gap -> Define as distâncias entre as colunas individuais de uma grade.
    • gap -> Propriedade abreviada para espaçamento entre linhas e espaçamento entre colunas.

    Grid Itens:

    • grid-row-start ->Define o início vertical de uma área da grade.
    • grid-column-start -> Define o início horizontal de uma área da grade.
    • grid-row-end -> Define o limite vertical de uma área da grade.
    • grid-column-end -> Define o limite horizontal de uma área da grade.
    • grid-row ->Shorthand property for grid-row-start and grid-row-end.
    • grid-column ->Propriedade abreviada para grid-column-start e grid-column-end.
    • grid-area ->Propriedade abreviada para linha de grade e coluna de grade.
    • justify-self -> Define o alinhamento de um item da grade dentro do contêiner da grade.
    • align-self ->Define para um item da grade como um único item da grade é posicionado ao longo do eixo transversal.
